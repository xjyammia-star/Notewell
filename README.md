# Notewell

一款基于 Electron 的本地知识库管理工具，面向学生用户，集成 AI 笔记整理、文章纠错、资料翻译与格式转换、课程表管理等功能，帮助提高学习效率、培养良好学习习惯。

## 主要功能

- 本地知识库：笔记的查看、编辑、搜索、文件夹管理
- AI 笔记：复习备考资料生成、知识点扩充、考试复盘
- 文章纠错：AI 检查拼写、语法、标点、搭配问题
- 资料转换：多语言翻译、多格式互转（md/txt/pdf/docx/图片OCR）
- 课程表：Week1/Week2 双周轮换课表，截图识别录入，上课提醒

## 技术栈

Electron + Node.js + 原生 HTML/CSS/JS
